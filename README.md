# 🤠 Ready Steady Bang

Remake moderne du jeu mobile **Ready Steady Bang** - un jeu de duel western "quick draw".

## 🎮 Gameplay

Affrontez des cowboys dans des duels au pistolet ! 
- Attendez le signal **"BANG!"**
- Tapez le plus vite possible
- Mais pas trop tôt, sinon vous êtes disqualifié !

## 🛠 Stack

- **Phaser.js 3** - Moteur de jeu 2D
- **TypeScript** - Typage strict
- **Vite** - Build rapide
- **Capacitor** - Export iOS/Android

## 🚀 Lancement

```bash
cd game
npm install
npm run dev
```

## 📱 Build Mobile

```bash
npm run build:mobile
npx cap open ios     # Ouvrir dans Xcode
npx cap open android # Ouvrir dans Android Studio
```
